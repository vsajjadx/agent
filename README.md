# AI Desktop Agent

ایجنت دسکتاپ شبیه Claude Desktop: روی کامپیوترت دستور شل اجرا می‌کنه، فایل می‌خونه/می‌نویسه/ویرایش می‌کنه،
توی فایل‌ها جستجو می‌کنه، صفحهٔ وب می‌خونه و با اسکرین‌شات + موس/کیبورد برنامه‌ها رو کنترل می‌کنه.

## پروویدرها
| پروویدر | توضیح |
|---|---|
| **Gemini** | API بومی گوگل (`generateContent` + function calling + thought signatures). کلید از <https://aistudio.google.com/apikey> |
| **Anthropic** | Claude |
| **OpenAI-compatible** | هر سرویسی با `/chat/completions` (OpenAI، OpenRouter، مدل‌های لوکال و …) |

وسط یک چت می‌تونی پروویدر/مدل رو عوض کنی (تاریخچه مستقل از پروویدر ذخیره می‌شه).

## امکانات
- چت‌های ذخیره‌شده (نوار کناری)، ادامه و حذف چت — در `~/.ai_agent/chats`
- پیوست تصویر (دکمهٔ 📎 ، Ctrl+V ، یا درگ‌اند‌دراپ) برای هر سه پروویدر
- رندر Markdown و کد، متن فارسی راست‌به‌چپ
- انتخاب پوشهٔ کاری (مسیرهای نسبی و دستورات شل از همون‌جا اجرا می‌شن)
- دستورالعمل سفارشی برای ایجنت (⚙ تنظیمات)
- «تست اتصال» و دکمهٔ 🔄 برای گرفتن لیست واقعی مدل‌ها از API
- توقف واقعی: دستور در حال اجرا هم kill می‌شه ، تلاش مجدد خودکار روی خطاهای موقت (429/503)
- ابزارها: `run_command` `read_file` `write_file` `edit_file` `list_dir` `find_files` `search_files` `fetch_url`
  `screenshot` `mouse_move` `mouse_click` `mouse_drag` `type_text` `press_key` `scroll` `wait`

## حالت‌های اجرا
- هر عملیات تأیید بخواد (پیش‌فرض؛ با گزینهٔ «اجازه برای همهٔ موارد این چت»)
- خودکار (فقط دستورات خطرناک مثل حذف/فرمت/خاموش‌کردن تأیید می‌خوان)
- کاملاً خودکار (بدون تأیید)

## اجرا از سورس
```
pip install -r requirements.txt
python ai_agent.py
```
کلید API رو می‌تونی توی ⚙ تنظیمات بدی یا با متغیر محیطی `GEMINI_API_KEY` / `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`.
کلیدها در `~/.ai_agent_config.json` (متن ساده) ذخیره می‌شن؛ اون فایل رو جایی به اشتراک نذار.

## دانلود exe
از بخش **Releases** همین ریپو فایل `AIAgent.exe` رو بگیر (ساخته‌شده خودکار با GitHub Actions).

## تست
```
python -m unittest discover -s tests -v
```
تست‌ها با سرور جعلی محلی اجرا می‌شن (بدون کلید و اینترنت) و حلقهٔ tool-use هر سه پروویدر رو بررسی می‌کنن.

## ساختار
- `agent_core.py` — ابزارها ، پروویدرها ، حلقهٔ ایجنت (بدون GUI)
- `ai_agent.py` — رابط PyQt6
