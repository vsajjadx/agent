# AI Desktop Agent

ایجنت دسکتاپ با کنترل سیستم (شل، فایل، موس/کیبورد، اسکرین‌شات) روی API کلاد یا هر API سازگار با OpenAI.

## اجرا از سورس
```
pip install -r requirements.txt
python ai_agent.py
```

## دانلود exe
از بخش **Releases** همین ریپو فایل `AIAgent.exe` رو بگیر (ساخته‌شده خودکار با GitHub Actions).

## حالت‌های اجرا
- هر عملیات تأیید بخواد (پیش‌فرض)
- خودکار (فقط دستورات خطرناک تأیید می‌خوان)
- کاملاً خودکار (بدون تأیید)
